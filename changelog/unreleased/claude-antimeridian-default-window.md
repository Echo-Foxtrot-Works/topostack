type: improvement
title: AI assistants can plan models across the antimeridian
---
Places that straddle 180° longitude, such as Fiji, Taveuni or the western Aleutians, can now be planned and linked from an AI assistant, and a browser agent can read and resend a studio design there. Give a box with west greater than east, as GeoJSON does. See the [project request reference](/guides/agent-api).
